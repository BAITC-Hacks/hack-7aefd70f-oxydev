# Развёртывание Oxydev для Mock Day #2

Статус на 28 сентября 2026: онлайн-стенд работает.

- URL: `https://oxydev.govtech-kz.com`
- приложение слушает только выделенный reverse-proxy порт `127.0.0.1:8017`;
- каталог на VPS: `/home/oxydev/qadam-ai`;
- Docker Compose работает в rootless Docker пользователя `oxydev`;
- user service Docker включён и для пользователя настроен linger;
- модель обучается при первом запуске, затем хранится в Docker volume;
- SQLite пилота и записи находятся в отдельном постоянном volume;
- облачный API-ключ на сервер не переносился; используется heuristic backend;
- S3-доступ из выданного PDF пока не используется: для Mock Day локальный
  volume надёжнее и не требует распространения дополнительного секрета.

## Проверка перед показом

```powershell
$env:QADAM_BASE_URL='https://oxydev.govtech-kz.com'
python scripts/demo_smoke.py
```

Ожидаются строки `OK health`, три `OK` для примеров и `OK counterfactual`.

## Важные ограничения

Стенд предназначен для синтетических и добровольных обезличенных ответов. На
нём пока нет production-ролевой модели, антивирусной проверки загрузок,
автоматической retention policy и юридически утверждённой политики согласия.
После Mock Day публичный доступ нужно либо закрыть паролем, либо остановить до
следующего контролируемого теста.

Серверные пароль, SSH-данные и S3-ключи находятся только в выданном PDF и не
записаны в репозиторий, документацию или Docker image.
