# Продуктовое решение: веб-сервис, не игра

## Что строим

Qadam AI — адаптивный веб-сервис с двумя частями:

1. **Applicant journey:** мобильный короткий сценарий EN / KK / RU, который помогает подготовить историю для уже существующего видео или даёт лёгкий вход в дополнительный интерактивный кейс, если заказчик его одобрит. Три вопроса текущего прототипа пока не подтверждены как обязательный этап приёма.
2. **Reviewer workspace:** исходные слова кандидата, структурированные свидетельства, прозрачная экспериментальная оценка там, где она проверена, ручной маршрут и журнал действий. Итоговое решение принимает человек.

Поставляется как responsive web-приложение с API; не требует установки из App Store. Позже его можно встроить в существующий портал по согласованному API и защитить ролями. Публичный доступ к текущему демо с реальными данными запрещён.

## Почему не игра

Игровые элементы уместны только для облегчения прохождения: прогресс из трёх шагов, мягкие подсказки, ясное завершение. Игровая механика с очками, таймером или «правильными» ответами будет измерять навык прохождения самой игры и доступ к устройствам/подготовке, а не компетенцию. Её надо отдельно валидировать; сейчас такой необходимости заказчик не подтвердил.

## Решение по языкам

Английский — язык интерфейса по умолчанию. Кандидат может выбрать казахский или русский. Язык ответа не является бонусом или штрафом. Текущий автоматический разбор — эксперимент только для русского текста; EN/KK передаются комиссии без балла. Для настоящего многоязычного скоринга нужны официальная методология и экспертная слепая разметка на каждом языке.

## Следующий продуктовый шлюз

Официальный процесс бакалавриата уже просит пример лидерства в видео. Поэтому перед выпуском следующей версии нужно выбрать вместе с заказчиком: (A) Qadam — добровольный помощник для подготовки видео, а оценка происходит по самому видео/интервью; или (B) Qadam — отдельный короткий интерактивный кейс, заменяющий часть существующей проверки, а не добавляющий нагрузку. Затем протестировать UX хотя бы с одним потенциальным абитуриентом и получить методологию. Не следует заставлять кандидата повторно описывать одну историю в трёх местах.
